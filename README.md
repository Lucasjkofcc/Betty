# Betty 
## Este projeto usa uv e ollama

- Necessita do modelo qwen2.5:3b e moondream:latest instalado no ollama

## Funções:
- Se não identificar nenhum rosto por 15 segundos pausa todos os players (youtube spotify etc) e bloqueia a tela (hyprlock)
- Avisa se sua bateria está baixa
- Pode pesquiasr na Web (usando DuckDuckGo)
- Tem tts e stt
- E faz mais umas coisas legais



(É uma continuação inidireta do meu outro projeto Jarvis)
